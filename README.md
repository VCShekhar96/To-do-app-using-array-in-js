# To-Do App Using JavaScript Arrays

A lightweight JavaScript to-do application demonstrating task management with an in-memory array.

## Overview

This project focuses on JavaScript fundamentals: arrays, functions, event handling, and DOM updates.

## Learning Goals

- Manage application state with arrays
- Add and remove tasks
- Update the DOM dynamically
- Practice event-driven JavaScript

## Getting Started

Clone the repository and open the HTML entry point in a browser.

## Next Step

A natural extension is persistent storage using the browser's `localStorage` API.
